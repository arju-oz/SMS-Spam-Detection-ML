SMS Spam Detection Using Machine Learning

Overview

A Machine Learning project that classifies SMS messages as Spam or Non-Spam using Natural Language Processing (NLP) techniques.

Technologies Used

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn

Models Tested

Model| Accuracy
KNeighborsClassifier| 81%
SVC| 88%
MultinomialNB| 90%
DecisionTreeClassifier| 91%

Best Result

DecisionTreeClassifier achieved the highest accuracy of 91%.
